<body_structure>
- **Rule:** Lead directly with the rule itself.
- **Why:** State the user's stated reason (often a past incident or strong preference).
  Why: Understanding intent enables edge-case judgment rather than blind compliance.
- **How to apply:** Specify when and where the guidance takes effect.
</body_structure>
