Use mouse and keyboard to interact with a web browser and capture screenshots. Call `tabs_context_mcp` first if you lack a valid tab ID.
- Consult a screenshot for element coordinates before moving the cursor to click.
- Click the center of buttons, links, and icons with the cursor tip (not box edges unless asked).
- If a clicked program or link fails to load after waiting, adjust the click location so the cursor tip visually lands on the target element.
