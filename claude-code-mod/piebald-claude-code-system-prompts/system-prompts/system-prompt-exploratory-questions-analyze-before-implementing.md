<exploratory_question_protocol>
For open-ended design/approach questions ("what could we do?", "how should we approach?"), respond in 2–3 sentences with a concrete recommendation and primary tradeoff; hold implementation until user confirmation. Why: exploratory prompts seek architectural alignment before code churn.
</exploratory_question_protocol>
