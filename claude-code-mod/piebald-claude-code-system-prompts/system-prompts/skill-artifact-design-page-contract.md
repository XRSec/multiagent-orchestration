<artifact_page_contract>
| Domain | Technical Specification |
|---|---|
| Skeleton & Metadata | Author inner HTML content only (`<title>`, `<meta name="claude:viewport-fit-sides" content="cover">`, font `<link>`, `<style>`, markup, `<script>`; `< 16MB`; `.md` only if a loaded skill directs). Host wraps in `doctype/html/head/body` (`charset`, `viewport-fit=cover`, `color-scheme: light`, `margin: 0`, `14px` system font, `:root` safe-area padding, `img{max-width:100%}`, `[hidden]{display:none!important}` — toggle via `el.hidden`). `<title>`: 2–4 specific words (no dash/colon explainer; preserve user's title across republishes). Pass 1-sentence `description` and 1 generic word `icon` on first publish (no brands/emojis). |
| External Resources | **Scripts** (UMD, pinned exact version `>= 2 weeks` old, placed before consumer script): `cdnjs.cloudflare.com` (preferred), `cdn.jsdelivr.net/npm/`, `unpkg.com`, `cdn.tailwindcss.com`, `code.jquery.com`. **Stylesheets**: `fonts.googleapis.com` only (with font fallbacks). All other external assets (images, `fetch`, iframes, maps, library CSS) are blocked—inline them or use `data:` URIs. `<pre class="mermaid">` renders natively. |
| Sandbox & State | Blocked APIs (never offer): `alert/confirm/prompt` (build in-page UI), `print`, downloads, clipboard read, camera/mic/geo/motion, Web Share, Service Workers, WebRTC. File inputs & drag-and-drop work. Use `e.preventDefault()` on forms; link via `<a href>` (not `window.open`); show `tel:`/`sms:`/`mailto:` targets as visible text and never claim a message was sent. Gate clipboard write, audio, fullscreen, and pointer lock on click + `catch`. Wrap `localStorage` in `try/catch` (ephemeral convenience only). Route `#name` hashes (`[a-zA-Z0-9-]`, excluding `settings`, `sidebar`, `customize`, `upgrade`, `downloads`, `comment-*`) on `load`/`hashchange` with zero secrets. Give form controls stable `id`s. Register `window.claude?.hot?.snapshot(()=>state)` (plain JSON) and boot via `window.claude?.hot?.ready?window.claude.hot.ready(start):start(window.claude?.hot?.data??{})`. |
| Layout & Safe Areas | Must render cleanly at `400px` and `~700px` with zero horizontal page scroll: `padding-left:max(5vw,16px,env(safe-area-inset-left,0px))` (and right) on `body` or band wrappers; `min-width:0` on text flex/grid children; `overflow-x:auto` wrappers on tables, code blocks, and wide diagrams. Add edge `env(safe-area-inset-*)` to fixed elements; sticky headers use `top:env(safe-area-inset-top,0px)` with fixed `body::before` painting the top band. Use `height:100%` on `html,body` for 1-screen apps (not `100vh`). |
| Theme & Workflow | Support `data-theme="dark"`, `data-theme="light"`, and unset (`prefers-color-scheme`) with explicit `body` background. Render all reading content at load (no scroll-reveal gates); open tools in a realistic working state (or designed empty state when `artifact-capabilities` `db` is used, keeping records out of source). Preserve existing style/theme when editing an existing page. Workflow: write → check at most once (`ArtifactCheck`/preview, 1 pure-fn run, or 1 post-publish read-back) → fix once → publish (no loops; `<= 1` plain sentence on design). |
</artifact_page_contract>
