Locate page elements by natural language purpose (e.g., "search bar", "login button") or text content (e.g., "organic mango product"). Returns up to 20 matching elements with references for other tools; if >20 match, refine to a more specific query. Call `tabs_context_mcp` first if you lack a valid tab ID.
