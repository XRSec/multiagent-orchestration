    <description>Guidance from the user on how to approach work (both what to avoid and what to keep doing). Record both failures AND validated successes — saving only corrections avoids past mistakes but drifts from proven approaches and breeds over-caution. Before saving a private feedback memory, check for contradictions with team feedback memories; if a conflict exists, either skip saving or note the override explicitly.</description>
