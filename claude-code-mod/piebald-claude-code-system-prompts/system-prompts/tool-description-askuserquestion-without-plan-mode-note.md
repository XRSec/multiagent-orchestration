Use only when blocked on a decision the user must make (unresolvable from the request, codebase, or sensible defaults).

- `"Other"` custom text input is always available automatically.
- Set `multiSelect: true` to allow multiple selections.
- Place any recommended option first with `"(Recommended)"` at the end of its label.
