# Paseo Bots Orchestration Plugin (`@oliexe/paseo-bots`)

Parent router: [../INDEX.md](../INDEX.md). Governs the multi-agent orchestration plugin (`paseo-bots/`), binding the 15-bot roster (`bot-chief` Global Assistant), 3-Tier Chief of Staff (`L1 -> L2 -> L3`), 4-pillar global Paseo navigation & cross-pillar deep links (`Bots`, `Team`, `Workflow` + `paseo-feed`'s `Feed (助理)`), isolated Managed Seats, Session Blackboards, dynamic 6-block system prompts, declarative Workflow DAG execution (`workflowRunRpc`), Task Pyramid settlement, model fallback chains, single-index Continuous Feed fusion (`botFeedReadRpc`, `BotFeedPane`), unified CLI auto-lifecycle/dispatch (`registerBotSessionLifecycle`, `paseo-chief-dispatch.mjs`), scheduled routines, friction analytics, and React Native / Web surfaces.

## 1. Global Invariants

- **Zero Target-Repository Pollution**: Isolate all session CWDs, `.agents/skills`, `.claude/`, and immutable run snapshots inside `$PASEO_HOME/plugin-data/paseo-bots/` via `ensureManagedSessionHome` and `assertInsideManagedDataDir`; NEVER write plugin runtime artifacts into external target code repositories or host global user configs (`assertNotGlobalUserConfig`).
- **Decoupled Asset & Envelope Persistence**: Persist `bots.json` inside the version 4 outer envelope (`{ "version": 4, "values": ... }`) under a 75 KB ceiling while externalizing standing instructions to `souls/<botId>.md`, MCP definitions to `mcp-servers/<id>.json`, and custom artwork out of inline Base64 Data URLs.
- **Dynamic Role-Aware Prompt Assembly**: Synthesize every chat turn's system prompt dynamically at launch (`systemPrompt` -> `promptSections` Blocks 1–6) according to `resolveSessionRole` (`dm | team-lead | team-direct-specialist | dispatched-worker`), keeping main host sessions free of static subagent roster bloat.
- **3-Tier Chief of Staff & Context Insulation**: Track delegation depth across `L1 -> L2 -> L3` via `TIER_DEPTH_LABEL` and `resolveTierDepth` (`shared/handoff.ts`), block Tier 3 workers from further `ask_bot` delegation, and strip noisy tool traces before upstream handoff via `extractInsulatedReply` (`server/tools/bots.ts`).
- **4-Pillar Global Navigation & Cross-Pillar Deep Links**: Register 3 primary sidebar pillars (`PaseoBotsSidebar` -> `Bots`, `PaseoTeamsSidebar` -> `Team`, `PaseoWorkflowsSidebar` -> `Workflow` rendered as top-level `WorkflowsRoute` without redundant `BackBar`, paired with `/feed`, `/team`, `/workflows` agent slash commands in `index.client.tsx`, `BOT_SCREENS`, `teamsScreen`, `workflowsScreen(scope?)`, `feedScreen(kind, id, title?)`, and `teamChatScreen(groupId)` in `client/screen-navigation.ts`) alongside `paseo-feed`'s `Feed (助理)` pillar, wiring bidirectional jumps across `WorkflowsScreen`, `TaskCardView`, `TeamMap`, `BotFeedPane`, and `BotsSurfaceReady`.
- **Global Assistant (`bot-chief`) & Single-Index Feed Fusion**: Tag `bot-chief` (`全局助理`) with `GLOBAL_ASSISTANT_LABEL` and `LONG_SESSION_ENABLED_LABEL` (`shared/bot.ts`), route across teams via `list_teams` and cross-team `ask_bot`, retain server `memoryPrefix` on short bypass turns in `Composer.tsx` and `BotLauncherCore.tsx`, scope `CompanionSessionManager` (`globalAssistantOnly: true`) to intent distillation + SHA-256 `MEMORY.md` sync on `LONG_SESSION_SYNC_METADATA`, and consume `~/.paseo/plugin-data/paseo-feed/index.jsonl` via `botFeedReadRpc` (`shared/rpc.ts`), `readMergedBotFeed` (`server/feed-bridge.ts`: classifying `"workflow"` before `"delegated"`, projecting `workflowTaskId`/`workflowId`/`workflowStageId`/`workflowStageName`, cursor slicing before selective hydration, `hydrated: false` fallback, read-only legacy `channels/*.jsonl` merge fallback), and `BotFeedPane` (`FEED_PAGE_SIZE = 20`).
- **Unified Auto-Lifecycle, Auth Backoff & Official Dispatch**: Register `registerBotSessionLifecycle` (`server/bot-lifecycle.ts`, with `oauthProxy` merged while `registerMcpOAuthLifecycle` passes `{ registerOpenHook: false }` for `agent.permission.before` only) as the single `agent.open.before` hook, mounting `bots`/`composio` MCP and `PASEO_AGY_BOT_PROMPT_FILE` (`ensureAgyPromptFile` -> `resolveEffectiveSystemPrompt` in `paseo-agy-acp/server/session.ts`) strictly when `LIFECYCLE_MOUNT_LABEL === "true"`. Halt scheduler daemon polling on auth errors (`isAuthConnectionError`) and apply exponential transient backoff (`nextRetryDelayMs` in `server/connection.ts`). Official CLI dispatch runs through `scripts/paseo-chief-dispatch.mjs`.
- **Host-Deterministic DAG & Lease Settlement**: Enforce DAG topological order (`validateWorkflowDAG`), inline/RPC launch (`workflowRunRpc` -> `startWorkflowFromRpc`, `resume_workflow`), concurrency fanout caps (`reserveMemberSlot`), cross-process lock safety (`acquireLease` via `O_EXCL` + tombstone rename), `TaskCard` `groupId`/`sourceChatId` propagation, and terminal state (`settleTask`) strictly in host code rather than trusting model prose claims.
- **Same-Provider Bounded Resilience**: Restrict automatic model failover (`runWithModelFallback`) to ordered `fallbackModels` within the active provider domain on transient capacity/quota errors, failing fast on auth, permission, or context-overflow faults.
